# Repository Guidelines

- Read the relevant `SKILL.md` before modifying a Skill.
- Keep each Skill independent and avoid unnecessary dependencies between Skills.
- Prefer clear, concise, and maintainable Markdown.
- Do not add scripts, dependencies, or complex directories without an explicit need.
- Inspect existing content before making changes.
- Do not create a Git commit unless the user explicitly requests it.
- After completing changes, report the modified files, their main content, and the validation results.
